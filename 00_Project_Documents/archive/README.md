# TALA Documentation Archive

Everything under this directory is non-authoritative. It is preserved as supporting evidence, implementation history, demonstration material, or obsolete/duplicate material. Archived wording such as "approved," "active," "current," "next," or "required" describes its historical context and grants no present execution or product authority.

| Location | Classification |
| --- | --- |
| `project-progress/` | Implementation history: rescue plans, task plans, audits, benchmarks, logs, and recovery evidence |
| `demo/` | Demonstration material and historical acceptance/test-case evidence |
| `tooling/` | Superseded agent/tool guidance preserved for traceability |
| `PAPER/`, `raw-source-files/`, `0/`, `45 FINAL SORTTED/`, `archive system req/` | Supporting research, business, and source evidence |
| `prd_modules_bck/` | Obsolete/duplicate PRD backup |
| `deprecated-shs-scope-2026-06-21/` and deprecated institutional workflow copies | Obsolete/duplicate material outside active college scope |
| Root-level prototype, data-dictionary, refinement, coverage, Alpine.js, reference, profile, low-fidelity, and security-test documents | Supporting evidence, implementation history, or demonstration material according to their subject; never authority |

Historical UAT or raw-source material that exists only in ignored local custody is not part of the portable repository evidence. Tracked extracts and current automated tests provide the discoverable evidence boundary; neither creates product authority.
