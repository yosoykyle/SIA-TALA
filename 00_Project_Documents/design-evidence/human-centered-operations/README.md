# Human-Centered Operations Design Evidence

This directory is the portable, non-authoritative evidence pack for the approved Human-Centered Operations direction. The [TALA Experience and Official-Output Design Definition](../../TALA-Experience-and-Official-Output-Design-Definition.md) explains how the evidence may guide production implementation. Canonical PRDs, the UI Surface Blueprint, and the Architecture Specification govern every conflict.

The original React prototype remains outside the repository. Its runtime, generated routes, sample actions, and data are not production source and must not be copied into TALA.

## Accepted use

- Compare hierarchy, branding, navigation, responsive transformation, operational language, and official-output presentation.
- Capture fresh production-stack screenshots at matching states and viewports for acceptance.
- Use the board as a composite direction, not a pixel-identical single-screen specification.
- Treat all names, identifiers, balances, statuses, and operational claims in these images as coordinated synthetic design data.

The pack does not prove backend behavior, authorization, provider health, official issuance, or completion of an owning Issue criterion. Current attributable production evidence is still required.

## QA summary

The representative prototype was reviewed across public, learner, Staff, operational-status, responsive-navigation, and official-output families. At the final capture checkpoint, the prototype build passed, the tested browser states reported no console warnings or errors, and no remaining P0, P1, or P2 visual defect was recorded. These historical results qualify the direction; they do not replace fresh production verification.
