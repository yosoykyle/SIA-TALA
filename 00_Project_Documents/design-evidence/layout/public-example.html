What governs this theme

Native structure
Keep the framework’s component structure, responsive layout tools, and interactions.
Cosmetic identity
TALA branding, Inter typography, green actions, neutral surfaces, and restrained button shading.
Requirements first
PRDs and the UI Blueprint determine fields and workflows. Examples illustrate; they do not define school policy.
Supported extensions
Use configuration and theming first. Document a real gap before recommending a plugin or custom component.

Native Filament uses its own mobile drawer and sidebar collapse. The earlier prototype’s hover, resize, bottom-bar, scroll-hiding, and pulse experiments are optional references.
